# Мой доход: курьер

Android-приложение на JavaScript и React Native CLI без Expo. Оно получает чеки из личного кабинета «Мой налог», показывает заработок и хранит копию данных в Firestore для работы без сети.

## Возможности

- Вход через ИНН и пароль личного кабинета «Мой налог».
- Защищённое хранение токенов; пароль не сохраняется.
- Обзор дохода за день, неделю и месяц, количества заказов и среднего чека.
- График заработка за 30 дней, список чеков с поиском по дате и расчёт налога по ставке 6%.
- Светлая и тёмная темы с сохранением на устройстве.
- Firestore-кэш чеков, дневных итогов и настроек устройства.
- GitHub Actions собирает debug и release APK; при теге `v*` прикрепляет APK к GitHub Release.

## Настройка Firebase

Перед запуском создайте Firestore Database и включите **Anonymous** в Firebase Authentication. Анонимная запись используется только как техническая защита кэша устройства; экран входа в приложение остаётся только через «Мой налог».

Опубликуйте правила из `firestore.rules` в Firebase:

```sh
firebase deploy --only firestore:rules
```

Не добавляйте `google-services.json` в репозиторий. Для GitHub Actions создайте секрет репозитория `GOOGLE_SERVICES_JSON`, содержащий однострочную Base64-кодировку Firebase-файла. Например, в Linux её можно получить командой `base64 -w 0 google-services.json`. Workflow восстановит файл только во время сборки.

## Запуск и сборка

```sh
cd mobile
npm ci
npm start
```

Для Android-разработки используйте Android Studio/эмулятор и выполните `npm run android`. GitHub Actions запускает `npm ci`, `eslint .`, затем `cd android && ./gradlew assembleDebug assembleRelease`. APK доступны в артефактах запуска workflow.

Release APK сейчас подписывается тестовым debug-ключом и не готов к публикации в Google Play. Для распространения через магазин добавьте собственный ключ подписи в GitHub Secrets и настройте release signing.

## Важно

Интеграция с «Мой налог» использует неофициальное API `lknpd.nalog.ru`; налоговая служба может изменить или ограничить его. Расчёт налога в приложении — сумма чеков, умноженная на 6%, а не официальный расчёт ФНС.
